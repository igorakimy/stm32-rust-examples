# ШИМ

**ШИМ** (PWM, Pulse-Width Modulation - широтно-импульсная модуляция) - способ изменения мощности нагрузки(яркости светодиода, скорости вращения двигателя и т.п.), при котором на нагрузку подаются быстро следующие друг за другом *импульсы*(замыкание и размыкание электрической цепи).

**Импульс** - всплеск электрического сигнала после каждого замыкания.

**Такт(период)** - цикл времени, за который происходит один импульс, когда шим замыкает и размыкает цепь один раз, измеряется а Герцах(Гц).

**Скважность** - время, на которое шим замыкает цепь. Чем больше скважность, тем меньше напряжение на выходе.

**Коэффициент заполнения** (Duty Cycle) - отношение длительности импульса к общему периоду сигнала, выраженное в процентах.

## Условные обозначения
**PWM** - ШИМ(широтно-импульсная модуляция)

**PSC** - prescaler, предделитель частоты

**ARR** - auto-reloaded register, максимальное значение счетчика таймера

**CNT** - текущее значение счетчика таймера


## Расчет частоты ШИМ 
**PWM Frequency = Timer Clock / ((PSC + 1) * (ARR + 1))**

Например, если:
```
Timer Clock = 90 MHz
PSC = 89
ARR = 999
```
то:
```
90_000_000 / ((89 + 1) * (999 + 1)) = 1000 Hz
```
