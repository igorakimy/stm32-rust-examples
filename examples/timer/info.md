# Таймеры

Таймер - это аппаратный периферийный модуль, который умеет:
- считать такты
- генерировать прерывания(interrupts)
- измерять время
- генерировать ШИМ-сигнал(PWM)
- считать внешние импульсы
- захватывать события
- запускать DMA(Direct Memory Access)
- управлять сервоприводами/моторами

### Особенности таймеров
- работают аппаратно
- независимо от CPU
- независимо друг от друга
- не блокируют CPU

### Типы таймеров
1. Базовый таймер (basic timer)
2. Таймер общего назначения (general-purpose timer)
3. Таймер с расширенным управлением (advanced-control timer)

### Принцип работы таймера (16 бит)
16-ти битный таймер умеет считать в диапазоне от 0 до 65535 
либо в прямом(Up), либо в обратном(Down) направлении: 
в памяти МК есть переменная, которая увеличивается/уменьшается на единицу 
с каждым следующим "тиком" таймера. При достижении заданного юзером 
значения (или максимального/минимального) счетчик сбрасывается, 
генерируется событие и отсчет начинается заново.
Таймеры тактируются (т.е. "тикают") от системной частоты и не потребляют ресурсов.
Частота по умолчанию для шины APB2 - 90МГц (90 миллионов "тиков" в секунду)

Чтобы понизить скорость отсчета используется **предделитель(prescaler)**.
Предделитель делит системную частоту на любое число от 1 до 65536. Например, 
если установить значение предделителя 3600, то таймер будет "тикать" со скоростью
25000 раз в секунду (90МГц / 3600 = 25КГц). Т.е. он будет доходить до максимального 
значения 65536 примерно за 2.62 секунды.
